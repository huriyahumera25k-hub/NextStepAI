2. FIX SERVICE UNDERSTANDING
==================================================

The application must correctly understand what the user wants.

→ Birth Certificate

"I want income tax"
→ Income Tax

"I want to apply for a driving licence"
→ Driving Licence

"I need an Aadhaar update"
→ Aadhaar

Do NOT default to Aadhaar or another service when the user's request is unclear.

If the request is ambiguous:

"I need a certificate."

"Which certificate do you need?"

Do not guess.

Use the existing service catalogue as the source of truth.

Use service names, aliases, descriptions, keywords, and natural-language intent where appropriate.

3. FIX VOICE INPUT
==================================================

Improve the existing voice-input system.

The flow should be:

Microphone
→ Listening
→ Final transcription
→ Display transcript
→ Intent/service detection
→ Response

The application must:

- clearly show when it is listening

- prevent duplicate submissions
- prevent stale transcripts from previous requests
- handle microphone permission errors
- handle no-speech errors
- handle recognition failures
- allow retry

User says:

User says:
